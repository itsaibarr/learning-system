## Learning requests

When the user wants to learn, study, understand, revise or be quizzed on a topic
("teach me X", "I want to learn X", "explain X so I understand it", "quiz me on X"),
run the learning session: follow `~/.config/opencode/commands/learn.md` with the topic
as the argument (or the user can type `/learn <topic>`). Use the `teach-understanding`
skill, never the global `teach` skill, and never produce a PDF or long document instead.
